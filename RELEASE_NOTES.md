# Peak Launcher v1.7.2 — Naprawione kliknięcia w MC 26.3 i odświeżone Peak Client GUI

## Co nowego
- **Naprawa obsługi myszy SDL3 w Minecraft `26.3`**: Poprawiono sprawdzanie lewego i prawego przycisku myszy (`InputConstants.MOUSE_BUTTON_LEFT = 1`, `MOUSE_BUTTON_RIGHT = 3`), dzięki czemu w **Peak GUI**, **Edytorze HUD (Drag & Drop)** oraz **liczniku CPS (LPM / PPM)** działają wszystkie kliknięcia i zakładki.
- **Nowy wygląd Peak Client GUI**: Zaokrąglone karty i przyciski z efektem ciemnego szkła, miękkie cienie, przełączniki typu pill toggle, ikony wektorowe dla modułów, odświeżony górski emblemat Peak oraz pasek skrótów klawiszowych.
- **Adaptacyjne skalowanie menu**: Całe okno Peak GUI płynnie dopasowuje się do dowolnej rozdzielczości i skali interfejsu Minecrafta (bez przycinania dolnych opcji i ucinania tekstu).
- Zawiera także kompaktowy domyślny układ HUD `72%` oraz przełącznik **Skala HUD** (`60% / 72% / 85% / 100%`).
